## 🎯 Overview
A modern, responsive portfolio website showcasing my skills, projects, and achievements. Built with HTML5, CSS3, and JavaScript, featuring a clean and professional design with interactive elements and smooth animations.

## ✨ Features
- **Responsive Design**: Optimized for all devices (mobile, tablet, desktop)
- **Interactive UI**: Smooth animations and transitions
- **Dark Theme**: Modern dark theme with gradient accents
- **Dynamic Content**: Animated typing text and hover effects
- **Professional Sections**:
  - Hero section with animated text
  - Featured projects showcase
  - Skills overview
  - Contact form
  - Achievement highlights

## 🚀 Setup and Deployment
1. Clone the repository:
```bash
git clone https://github.com/hemant684/Hemant-Chaudhary-Portfolio.git
```

2. Navigate to the project directory:
```bash
cd Hemant-Chaudhary-Portfolio
```

3. Open `index.html` in your browser or use a local server:
```bash
python -m http.server 8000
```
